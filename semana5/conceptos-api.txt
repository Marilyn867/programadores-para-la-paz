La ruta POST /reporte permite recibir información enviada por un usuario mediante una solicitud HTTP POST. En este caso, el servidor recibe un mensaje desde el cuerpo de la solicitud y responde con un objeto JSON indicando que el reporte fue recibido correctamente.

Esta ruta podría servir en una aplicación comunitaria para enviar reportes ciudadanos, alertas de seguridad, daños en vías, problemas de servicios públicos o situaciones de emergencia. De esta manera, la información puede organizarse y procesarse de forma más eficiente.
