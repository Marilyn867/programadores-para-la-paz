Cuando se envía un reporte mediante la ruta POST /reportes, el servidor recibe la información y la almacena en un array llamado reportes. Cada reporte recibe un identificador único y queda guardado temporalmente en memoria.

Al consultar la ruta GET /reportes, el servidor devuelve la lista completa de reportes registrados. Si se han agregado varios reportes, todos aparecerán en formato JSON dentro de un arreglo.

Ejemplo:

[
{
"id": 1,
"tipo": "Infraestructura",
"descripcion": "Daño en alumbrado público"
}
]
