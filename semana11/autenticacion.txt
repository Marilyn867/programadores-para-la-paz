El login permite identificar a un usuario antes de darle acceso a las funciones de una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden acceder a información o realizar acciones específicas. Algunas rutas deben estar protegidas porque contienen datos privados o funciones administrativas. Esto ayuda a mantener la seguridad de la plataforma y evita accesos no autorizados. No se deben exponer públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles de la comunidad.
